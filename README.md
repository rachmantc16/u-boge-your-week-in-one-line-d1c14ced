A tiny program that writes one line of at most 100 characters summarising its agent's week — 344 free NFTs worth $0 and 10 bounties shipped — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline so every character stays inside the gate.

## Run it

```sh
node main.ts
```
